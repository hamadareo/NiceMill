# 人物の枠の取りこぼしと「無名の枠」(extra_boxes)

試合動画では、エンジンの人物 P1..Pn（最大 max_people）の枠が動画の約半分の時間しか付かず、
画面上の選手の約半数に枠が付かなかった（公開CC動画 Samsunspor TBF で 6 場面 74 人中、
プレーヤーに出る枠は 35 人 = 47%）。検出器は 64 人（86%）を見つけている。落ちていた段階は
追跡のつなぎ（P1..Pn に採用されない断片）と、パッケージに入らない人（よかった場面がない人）。

`pfb_app.export.extra_boxes`（numpy のみ・読み取り専用・DB変更なし）は、人物に採用されなかった
検出を「名前のない枠」として返す。人物の枠・同一人物の判定には一切触らない。

- `extra_boxes(raw, kept, fps)`: raw_tracks.txt と boxes.txt の行から無名の枠の行を返す
- `load_extra_boxes(tracks_dir)`: tracks/<video id>/ から読む（ファイルがなければ空）
- `player_rows(ex, step)`: ページの JSON 用 [[frame,x,y,w,h],...]

採用条件: 人物の枠と重ならない／0.4秒以上続く／足元が、人物たちの足元が作る範囲（前後4秒、
凸包を人の背丈ぶん広げた範囲）の中／背丈が、人物の背丈と足元位置の関係から外れない／同じ
トラックの6割以上で成り立つ／同じ人への二重の枠は除く。観客席・ベンチ奥・記録席の人はほぼ除かれる。
コートの登録は要らない。

振り返りプレーヤー（review-video 側）へ入れる手順は IMPROVE.md（作業記録）を参照。
