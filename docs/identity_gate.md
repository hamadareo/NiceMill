# 同一人物の確認（correct_later の出力の安全装置）

追跡は、別の人の軌跡を1つのラベルにつなげることがある。承認のない出力（`correct_later`）では、同じ人と確かめられた人だけを通常のページに載せる。`approve` の作業には影響しない（承認が確認の役を持つ）。書類の作業には、取り違える追跡も背番号もないので、かけない。

## 何を見るか（既存のデータだけ。映像から新しく測らない）
- 名前づけの段階が、ラベルの軌跡に沿って約6秒ごとに読んだ背番号（`cues.number[ラベル].timeline`。ほとんどが空、ときどき別の数字）と、その最頻の番号（dominant）。
- `pipeline.identity_check.event_states`：その人の各場面が、同じ番号（SAME）／別の番号（FOREIGN）／近くで読めていない（UNKNOWN）。
- 1人に複数ラベルがあり最頻の番号が違う（混在）、ほかのラベルが同じ番号を読んでいる（重複）。
- 「人を確かめる」で評価する人が決めた記録（2026-11-23 から）：画面で直して保存した割り当て（identity の実行の source が `teacher`）と、そのまま「これで決定して次へ」「参加者の特定を確認」を押したときの割り当て（`review.mark_people_checked` がグループの `meta.people_checked` に identity の実行の番号を残す。監査ログ `people_checked`）。自動の人物選び（`auto_people`、source `auto`）と自動の確認（`auto_confirm`）は、人が決めたことにならない。

## 背番号での判定（`export/identity_gate.py` の `assess`、既定は厳しめ）
- 同一人物と確かめられた（ok）：最頻の番号の読みが `min_reads`（3）回以上かつ読んだ番号の `min_share`（0.6）以上、SAME の場面が `min_same_scenes`（3）件以上、FOREIGN なし、混在・重複なし。
- 別人混入が確か（mixed）：FOREIGN の場面がある、または1人のラベルが違う最頻の番号を読んでいる。
- 疑わしい（doubt）：上のどちらでもなく、確かめる手がかりが足りない（番号が読めていない、読みが少ない、重複、SAME の場面が少ない）。
- 閾値は `settings.identity_gate`（`min_reads`、`min_share`、`min_same_scenes`、`allow_foreign`）で変えられる。

## PDF に載せるかどうか（`decide`。スポーツでも、スポーツ以外でも同じ）
次のどれかなら載せる。どれでもなければ載せない（評価者用の一覧に「入っていない（同一人物の確認が取れていない：理由）」）。
1. **背番号で確認できた**（NUMBER）：`assess` が ok。SAME の場面だけを使う（下）。
2. **「人を確かめる」で評価する人が確認・名前付けした**（CHECKED）：その人の文のもとになったカメラの割り当て（各カメラの behavior の実行のもとの identity の実行）が全部、人が決めたもの（上）で、その人を割り当てている。場面は承認の作業と同じように全部使う（文が引用している場面の写真も載せる）。1場面ずつの確認はしない。取り違えていたら「この文は間違い」（人物の取り違え）で直す。
3. **作業の中に確かめる手がかりが1人分もない**（NO_CLUE）：評価の対象の人のどのラベルにも最頻の番号がなく（背番号がだれにも読めない）、どのカメラの最新の割り当ても人が決めていない（`work_has_clue` が False）。このときは全員を、いつもの correct_later の表示（AIが作成した文・確認状況・訂正の記録）で載せる（冊子と同じ）。ページには「背番号の読み取りも「人を確かめる」の記録もない作業のため、同じ人かどうかは確かめていません。」と書き、ステップ5の一人ずつの画面に「人を確かめると、取り違えを防げます。」と出す。

手がかりは作業ごとに見る。1人でも背番号が読めたり、1つのグループでも人が割り当てを決めたりすると、確かめられない人は載せない（手がかりのある作業で、確かめられない人だけを黙って載せることはしない）。

## 出力への効果（correct_later のみ）
- NUMBER の人は、SAME の場面だけを根拠の写真・場面の数・時間の流れに使う。「映っていた時間」も、最頻の番号が読めている区間だけにする。
- CHECKED の人は、全部の場面を使う（承認の作業と同じ）。映っていた時間は割り当てどおり（番号の区間に限らない）。ページに「「人を確かめる」で確かめた人です。」。
- コートの位置と移動距離（コートを登録した作業だけ）は、どの通り方でもラベルの軌跡全体から描く（番号の区間に限らない）。前の版のこの文書には「出さない」とあったが、実装は前から出していた（2026-11-23 に文書を実装に合わせた。出さないようにするかは未決）。
- 評価者用 PDF の表紙のグラフと一覧の「よかった場面」は、載せた人（NUMBER・CHECKED・NO_CLUE）を数える。載せない人は「集計していません」（`Sheet.ident_blocked`）。
- 除いた場面があるときは、ページに「確かめられなかった場面N件は除きました（文はそれらも含めて作られています）」と小さく書く（文は元の全場面から作られているため）。
- 冊子（`booklet.build(identity_gate=True)`）：表紙と奥付に「同一人物の確認を通った人だけを掲載しています」。NO_CLUE で全員を載せたときは、代わりに「背番号の読み取りも「人を確かめる」の記録もない作業のため、同じ人かどうかは確かめずに掲載しています。」と、追跡の取り違えの注意。0人のときは4ページ（表紙・目次・この冊子について・奥付）で、奥付に「同一人物と確かめられた人がいなかったため、人物ページはありません」と書く。
- 参加者に届くほかの出力（成長の記録の数、解説動画）も同じ判定を使う（`sheets.person_moments`）。評価する人が見る「試合・活動のまとめ」と「ききたいことを聞く」は、全員を確認状況つきで見せる（承認の作業と同じく、評価する人のための画面のため）。
