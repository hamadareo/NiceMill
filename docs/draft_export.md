# 下書きも出すPDF（drafts=True）

目的：公開クリップを実際に処理した結果を、評価する人の承認を作らずにPDFとして見せる。

- `render_student_pdf` / `render_teacher_pdf` / `export.pdf._html` の `drafts=True`（既定は False。既存の挙動は変わらない）。
- 有効のとき、承認していない人でも、最新の文（`pfb`）があれば出力に入る。入るのは、確認待ちと、短い文の承認待ち（文はある）の人。承認の操作はしない。承認の状態も変えない。
- 各人のページの上に「未承認（下書き）。評価する人はまだ確認していません。」の赤い帯、文の上にも同じ注意、各ページの下に「承認した出力ではありません」を出す。「確かめたものです」の脚注は下書きのページには出さない。
- 評価者用PDF：表紙に件数（未承認 n 人・承認済み m 人）と注意、一覧と人ごとのページの札に「未承認（下書き）」、文章の出所の行にも状態が出る。承認済みと混ざるときは、ページごとに状態が違う（承認済みのページに赤い帯は付かない）。
- 出典：`credits=[...]` に素材の出典の行（ライセンス名、改変の有無）を渡すと、各参加者ページの末尾と評価者用の末尾に出る。`drafts=True` で出典を渡さないときは「出典：作業の設定で未入力」と出る。`drafts=False` で `credits` なしのときは何も出ない（従来どおり）。
- 作業ごとの出典を保存する場所はまだない（引数で渡す）。画面からの設定は未実装。
- テスト：`tests/test_draft_export.py`。

## 1人1ページ・背番号の呼び方（下書きオプションのとき）

- 参加者に渡す形式は、1人が A4 の1ページに収まる（余白とフォントを詰めた配置。文章、根拠の場面の写真、時間の流れ、場面の種類のグラフ、あれば確定ヒントを全部残す）。PDF のページ数＝人数。
- 呼び方は「選手2」「#8」「〜さん」をやめ、背番号で出す（export/jersey.py）。確定（名簿の背番号、またはコーチが入力した「#n」）は「背番号 8」、AI が読んだもの（name_source が number、または出どころがない「#n」）は「背番号 8番？（推定）」、まだ読めていないもの（「選手n」）は「背番号 不明」。どれにも「人物ID n」（participant_id の番号）を小さく添える。「さん」は付けない。
- 背番号の読み取りは精度のゲートを通っていないため、AI の読み取りは断定しない（推定と書く）。
- 文の中（AI が書いた本文、場面の説明）の呼び方は変えない。本文は人名を含まない作りで、この出力では「選手2さん」などは見つからなかった。場面の説明の「あなたは…」は従来どおり。
- どちらも drafts=True のときだけ。既定（drafts=False）の画面・PDF は従来どおり。

## 参加者用 PDF から状態の帯を外した（追記）
- 参加者に渡す形式（student）には、赤い帯・「未承認」「評価する人はまだ確認していません」・全ページ下の注意を出さない。代わりに、ページ末尾の出典の近くに、小さい中立の1行「AIが作成した文です。誤りがあれば訂正できます。」だけを入れる（枠も色もなし）。
- 評価者用（teacher）の PDF は内部の確認用なので、状態の表示（承認済み・未承認の下書きなど）を残す。
