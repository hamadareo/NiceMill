# 製本用の冊子（export/booklet.py）

`booklet.build(repo, assignment_id, credits=, contact=, subtitle=, credit_short=)` が A4 縦の冊子 PDF を作る。既存の1人1ページの student PDF は変えない。

## 構成（総ページ数は必ず4の倍数）
- p1 表紙（右ページ）。最終ページが裏表紙（奥付）。
- p2 から見開き（左ページ＝偶数、右ページ＝奇数）。1人＝1見開き2ページ。左：背番号・人物ID・AIが作成した文（全文）・根拠の場面の写真。右：時間の流れ・場面の種類のグラフ・（あれば）ヒント・確認状況（訂正なし／訂正済み 版N／誤りの報告あり）・出典とAI作成の1行。左右とも見出しに同じ背番号と人物IDを出す。
- 人数が偶数のときだけ、p2–3 に補いの見開き（左：目次、右：この冊子について・出典）を入れて、総ページを4の倍数に揃える（人物の見開きは p4 から）。奇数のときは補いが要らず、奥付に「この冊子について」と目次を載せる。総ページ＝（先頭2か4）＋2×人数。9人なら20ページ。0人でも4ページ。
- 文のない人（場面が少ない人）は見開きを作らず、「この冊子について」に「場面が少なく文のない○人は、載せていません。」と書く。
- 承認・未承認・下書きの語は使わない。呼び方は背番号（docs/draft_export.md と同じ規則）。

## 製本の余白
- 外側 15 mm、内側（のど）22 mm（左ページは右が内側、右ページは左が内側）。上 14 mm、下 20 mm。
- ノンブルと NiceMill のロゴ（主色 #C8410C）は外側の下。表紙は出さない。
- 1ページごとに別の文書として描き、はみ出すときは文字と図を段階的に小さくして1ページに収める（最小 0.64 倍）。

## 面付け
`booklet.impose_a3(pdf)`：A3 横に2面ずつの中綴じ順（外の紙の表＝最終ページ｜p1、裏＝p2｜最終-1、…）。紙の枚数＝総ページ÷2。

## テスト
tests/test_booklet.py（人数 0・1・5・9・10 で4の倍数・表紙と裏表紙・左ページが偶数・左右が同じ人・旧表記や承認の語が0件・ノンブルの連続・面付け）。

## 空白を埋める（各ページ90%以上）
- 各ページは、一番大きく収まる倍率を探す（写真・図・余白は倍率に比例、文字は11pt／文14ptを下限に最大1.3倍まで）。左ページの根拠の場面写真は、その人の文に使った場面を全部（最大8枚）並べる。右ページは、事実の情報（よかった場面の数、場面の種類の内訳、映っていた時間・区間）と、根拠の場面の表（時刻・したこと・よかった理由）を、入れた方がページが埋まるときに入れる。文に使った場面の写真がない人の左ページには、記録された場面の表を入れる。順位づけ・比較・新しい数字は入れない。
- 表紙は、題・ロゴ・作業名を大きくし、公開クリップ由来の写真1枚（人物の切り出し）を入れる。
- 占有率はレイアウトから測る（`booklet._occupancy`）。本文領域（上14mm〜下20mm）に対する内容の高さ。

## 表紙と奥付（書籍らしい表紙）、同一人物の確認は冊子では使わない
- 表紙（p1）：写真なし。上から、シリーズ名（小さい字）、題「NiceMill 処理出力」（Noto Sans CJK JP 900、主色 #C8410C）、副題、細い罫線、著者（濱田 怜央、酒造 正樹（湘南工科大学））、発行日と版、下部に GitHub の QR コード（36mm 角相当・白地に黒、segno で作る）とその URL、「公開準備中」、最下段に素材の出典1行。角丸のカード・影・グラデーションは使わない。
- QR の宛先・注記・版・著者は `booklet.build` の引数と既定値（`REPO_URL`、`REPO_NOTE`＝既定は注記なし（非公開の間だけ `repo_note="公開準備中"` を渡す）、`EDITION`、`AUTHORS`、`SERIES`）で変える。`segno` が必要（pyproject に追記）。
- 奥付：著者、GitHub の URL（QR は表紙のみ）、小さい1行「人物の追跡に取り違えが含まれることがあります。」（`booklet.html.j2` の `id="tracking-note"`／`about.tracking_note`。消すときはこの1行だけ）。
- `booklet.build(identity_gate=False)`（既定）：同一人物の確認（docs/identity_gate.md）を冊子では使わず、文のある人は全員載せる。`identity_gate=True` で確認を通った人だけにする。student や評価者用など、ほかの出力の既定は変わらない。

## デモ版（`export/demo.py`）

学会デモ用に、確かめられている所を前に出した別の出力。`booklet.build` は変えず、全員を載せる冊子はそのまま残る。

- 場面ごとの確認（`export/demo_scenes.py`）。人物は外さず、場面を一つずつ判定する。三つとも成り立つ場面だけが「確かめられた場面」になる。
  (1) その人物IDで最も多く読み取られた背番号が、場面の前後（背番号の読み取り間隔の1.5倍、ここでは9秒）以内に読み取られている。
  (2) 場面の前後1秒で、人物の枠がほぼ全フレーム（90%以上）にあり、体の高さの半分を超えて飛ばない。
  (3) その間、ほかの人物の枠と半分以上重ならず、ほかの人物が同じ背番号を読まれていない。
  手がかりであり、同一人物の証明ではない。枠が連続して見える中での人物の入れ替わりは、このデータでは見つけられない。
- 人物ページは、確かめられた場面が2件以上の人だけ（強い順）。該当が4人未満なら1件以上に下げ、1件の人は「推定」と明記する。
  ページの写真・数・表は確かめられた場面だけを使う（文章は確かめられなかった場面も含めて作られていることを、ページに書く）。
- 検出の例: 一人の人物IDの枠を、連続121フレーム（約4秒）、0.5秒おきの9枚で示す。区間は、枠が全フレームにあり、飛ばず、
  ほかの人物の枠と半分以上重ならず、別の背番号が読まれていない所から選ぶ（確かめられた場面を含む区間を先に）。
  人物1人につき最大2例、全体で最大8例（2例で見開き1つ。奇数なら「検出の例の見方」ページが相手になる）。
- 検出の数字: この公開クリップで測った値（長さ、人物IDの数、背番号が読めたID、1フレームあたりの枠、途切れず飛ばない最長区間、
  確かめられた場面の数、人物ごとの値）と、開発ブランチの再現率（Samsunspor 60秒版 47→85%、車いすバスケ 74→86%）。
  後者は別のクリップで測った値で、本番に未反映、この3分版では測っていないと明記する。
- 奥付に「掲載は、同一人物と確かめられた場面を選んだ例である。全N人のうち、人物ページを載せたのはM人。…」と、
  確かめられた場面の件数（全体と掲載した人）、判定の基準、手がかりであることを書く。
- ページ構成: 表紙、（目次・この冊子について）、人物の見開き、検出の例の見開き、検出の数字の見開き、奥付。4の倍数。
- 試験（`tests/test_booklet_demo.py`）と独立の照合（枠の記録から各例を数え直す）で、各例の連続性を確かめた。
